SHREE MART — ULTIMATE MODERN APP
===================================

This package upgrades the current Shree Mart catalogue into a premium,
app-like storefront while keeping the existing product catalogue,
search, filters, product details, enquiry cart, FAQ and WhatsApp flow.

NEW
---
• Premium navy + gold visual system
• Sharper typography and stronger contrast
• App-style quick-shop category rail
• 3-step order guidance
• Mobile bottom navigation
• Ctrl/Cmd + K smart search shortcut
• PWA manifest + service worker for installable app behavior
• Offline app-shell caching when deployed over HTTPS
• Existing 390-product catalogue retained
• Existing WhatsApp number and enquiry flow retained
• No server/database required

FILES
-----
index.html
manifest.webmanifest
sw.js
icon-192.png
icon-512.png

RUN
---
For a simple test, open index.html in a browser.

For installable PWA behavior and service-worker support, deploy the folder
to Vercel, Netlify, GitHub Pages, or another HTTPS host.

WHATSAPP
--------
The current site uses the WhatsApp number already present in the original
Shree Mart page. Update the number inside index.html if the store number changes.
